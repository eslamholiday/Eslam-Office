# Eslam Office

تطبيق Android عربي محلي لإدارة مكتب السفر والحسابات، من الصفر بـ **Flutter + SQLite**. الاسم التجاري داخل الكشوف قابل للتعديل، وافتراضيًا **Eslam Holiday**.

## التشغيل

- Flutter 3.35.4 / Dart 3.9.2، JDK 17، Android SDK 36، NDK 27.0.12077973.
- `flutter pub get --enforce-lockfile`
- `flutter analyze`
- `flutter test` (على Linux يحتاج `libsqlite3-dev`).
- `flutter run`
- `flutter build apk --debug --target-platform android-arm64,android-x64`
- للإصدار الموقّع: جهّز `android/key.properties` ثم `flutter build apk --release --target-platform android-arm64`.

GitHub Actions يجري التحليل والاختبارات ثم ينشر APK تجربة ضمن Artifacts. نسخة التجربة لها معرف `.preview`، ويمكن تثبيتها بجانب النسخة الموقعة. مفتاح الإصدار الخاص لا يُرفع إلى المستودع. لإصدار موقّع من Actions أضف الأسرار `ANDROID_KEYSTORE_BASE64` و`ANDROID_STORE_PASSWORD` و`ANDROID_KEY_PASSWORD` باستخدام **المفتاح الأصلي نفسه**، والاسم المستعار `eslam-office`.

## المزايا المنفذة

- واجهة عربية RTL، دخول مباشر، قاعدة محلية، بيانات مالية فارغة عند أول تشغيل.
- العملاء، المسافرون، العائلات، وجهات الإصدار؛ كل حساب يدعم العملتين بأرصدة مستقلة.
- تذاكر بثلاث فئات ADT/CHD/INF وعدد وأسعار منفصلة؛ أقسام الطفل والرضيع قابلة للطي.
- عمولة افتراضية للطيران وأولوية قاعدة الطيران × جهة الإصدار؛ Snapshot داخل العملية.
- وضع خصم العمولة من الأساسي أو إضافة رسم إصدار لكل تذكرة.
- الفنادق بتكلفة وبيع **الحجز الكامل**؛ حساب الليالي من التواريخ.
- الفيزا بسعر وحدة × عدد، والتسويات والأرصدة الافتتاحية والمصروف الشخصي/المكتبي.
- مسودات دون أثر مالي؛ الاعتماد والقيود في معاملة SQLite واحدة.
- استرجاع كامل/جزئي مع منع تجاوز الرصيد المتبقي؛ تصحيح بيع بقيد عكس وبديل ذرّي.
- البحث الموحد باسم الزبون أو هاتفه أو رقم العملية، وفتح النتائج مباشرة.
- PNR ملغى بالكامل ولا يظهر في النماذج أو البحث أو الكشوف.
- كشوف العملاء والموردين PDF عربية بخط مضمّن ومعاينة وحفظ ومشاركة، مع شعار اختياري.
- تحويل عملة **العرض فقط** بسعر 100 USD مقابل IQD؛ عمولة التحويل بالألف للعرض فقط.
- تقارير الأرباح والفلاتر، وإخفاء مبالغ الرئيسية، وعرض الحساب كجدول أو حركات.
- مرفقات من الكاميرا والصور والملفات مع نسخها إلى التخزين الداخلي الدائم؛ معاينة صور دون قص ابتدائي.
- رقم الهاتف يُدخل يدويًا؛ الضغط عليه يتيح الاتصال أو WhatsApp أو النسخ دون استيراد جهات الاتصال.
- إعدادات الثيم واللون والخط والحجم والكثافة، وترتيب التنقل وبطاقات الرئيسية والحقول الاختيارية بالسحب والإظهار/الإخفاء.
- صور أو شخصيات بروفايل محلية للزبائن وجهات الإصدار، مع حفظ دائم داخل التطبيق.
- حذف إجباري للعمليات مع إزالة آثارها ذرّيًا وإمكانية التراجع من سجل التعديلات.
- حفظ الكشوف كصور PNG داخل التطبيق إضافة إلى PDF والمعاينة.
- عرض المبالغ بفواصل آلاف ومن دون كسور عشرية مرئية.
- قوائم طيران ومدن ودول جاهزة قابلة للتعديل والتعطيل، وافتراضيات من القوائم المحفوظة.
- أرشفة الحسابات واستعادتها دون فقد تاريخها المالي، وسجل تعديلات.
- لا نسخ احتياطي ولا تسجيل دخول ولا مستخدمون متعددون ولا خلط عملات.

## المعادلات

الأموال أعداد صحيحة: سنت للدولار ووحدة للدينار؛ النسبة أجزاء من 10000. لا تُخزّن الأموال كـ double.

لكل فئة تذكرة:

```
commission = round(baseMinor * percentHundredths * quantity / 10000)
cost       = grossMinor * quantity - commission
sales      = sellMinor * quantity
profit     = sales - cost
```

في وضع رسم الإصدار: `cost = (grossMinor + feeMinor) * quantity` والعمولة المخصومة صفر.
الفندق: `profit = fullBookingSale - fullBookingCost`، دون ضرب إضافي.
الفيزا: `sales = unitSale * quantity` و`cost = unitCost * quantity`.
التسوية والرصيد الافتتاحي لا ينشئان ربحًا. المصروف الشخصي لا يخفض صافي ربح المكتب.

## هيكل المشروع

- `lib/domain.dart`: العملات، الأرقام العربية، التقريب، المعادلات والقيود.
- `lib/store.dart`: SQLite، المعاملات الذرية، دفتر الحسابات، الاسترجاع والأرشفة.
- `lib/forms.dart`: نماذج الإدخال.
- `lib/pages.dart`: الحسابات والعمليات والبحث.
- `lib/reports.dart`: الكشوف وتقارير PDF وتحويل العرض.
- `lib/settings.dart`: التخصيص والقوائم والعمولات.
- `lib/ui.dart`: عناصر الواجهة والمرفقات.
- `lib/main.dart`: الفتح والثيم والتنقل والرئيسية.

قاعدة `eslam_office.db` في مسار قواعد البيانات الخاص بالتطبيق. المرفقات في `getApplicationDocumentsDirectory()/attachments`، ولا تُخزن أسرار التوقيع أو بيانات العملاء داخل Git.

## التحقق وحدود الإصدار الأول

اختبارات آلية للرياضيات وفصل العملات والقيود والاسترجاع والأرشفة والواجهة. نجاح البناء لا يعوّض تجربة الأجهزة الفعلية: الكاميرا، منتقي الملفات، جهات الاتصال، المشاركة، الطباعة، إعادة التشغيل، وأجهزة Samsung تحتاج اختبارًا فعليًا.

بعض تفاصيل التخصيص المتقدم في المواصفات القديمة ليست ضمن هذا الإصدار: شخصيات متحركة متعددة الحالات، سحب حر لعناصر الشاشة، حزم أيقونات مخصصة، وإدارة كاملة للأصوات والتنبيهات. لا تعرض الواجهة أزرارًا وهمية لهذه الوظائف.

خط Cairo مرفق بترخيص OFL داخل `assets/fonts/OFL.txt`.
